# Grill Me

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one.

## Rules for Questions
1. **One at a time**: Ask the questions one at a time.
2. **Build context**: Each question MUST build on the previous answer.
3. **Be brutal**: Challenge assumptions with "Is that actually true?" or "What happens if this fails?".
4. **Go concrete**: Ask about requirements, edge cases, user experience, and failure modes.
5. **No output yet**: Do not write a plan document or code until I say we are aligned.
