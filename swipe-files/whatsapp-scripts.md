# Swipe File: WhatsApp Scripts — COD Confirmation & Follow-up

> WhatsApp is the MENA sales floor. These scripts are for the critical moments: order confirmation, delivery follow-up, and win-back. Written in عامية (colloquial) because that's how people actually talk on WhatsApp.

---

## 1. Order Confirmation (within 1 hour of placing order)

### Egyptian عامية
```
أهلاً [الاسم] 👋

تم تسجيل طلبك بنجاح! ✅

📦 المنتج: [اسم المنتج]
💰 السعر: [المبلغ] جنيه
🏠 العنوان: [العنوان]

علشان نتأكّد الطلب، ممكن تأكّدلي العنوان؟
لو عندك أي سؤال، أنا هنا 😊
```

### Gulf عامية
```
هلا [الاسم] 👋

تم تسجيل طلبك بنجاح! ✅

📦 المنتج: [اسم المنتج]
💰 السعر: [المبلغ] ريال
🏠 العنوان: [العنوان]

عشان نتأكد من الطلب، ممكن تأكد لي العنوان؟
إي سؤال أنا حاضر 😊
```

### Why this works:
- Confirms the order immediately (reduces cancellation)
- Asks for address confirmation (catches errors early)
- Friendly, not robotic

## 2. Delivery Day Reminder

### Egyptian عامية
```
أهلاً [الاسم] 👋

طلبك في السكة! 🚚
المندوب هيتواصل معاك النهاردة.

لو مش هتبقى موجود، ممكن تقولي أحسن وقت؟
```

### Gulf عامية
```
هلا [الاسم] 👋

طلبك في الطريق! 🚚
الموزع بيتواصل معك اليوم.

إذا ما بتكون موجود، تقدر تقولي الوقت المناسب؟
```

## 3. Post-Delivery Follow-up (24h after delivery)

### Egyptian عامية
```
أهلاً [الاسم] 👋

وصلك الطلب؟ عجبك المنتج؟ 😊

لو عندك أي ملاحظة، أنا هنا.
لو عجبك، ممكن تسيب تقييم؟ بيساعد ناس تانية تقرر ❤️
```

### Gulf عامية
```
هلا [الاسم] 👋

وصلك الطلب؟ عجبك المنتج؟ 😊

إي ملاحظة، أنا حاضر.
إذا عجبك، ممكن تترك تقييم؟ يساعد ناس ثانية تقرر ❤️
```

## 4. Win-Back (no response to confirmation)

### Egyptian عامية (after 24h)
```
أهلاً [الاسم] 👋

ملاحظة صغيرة عن طلبك — لسه متأكّدناش العنوان.
لو مش مهتم، مفيش مشكلة خالص! بس لو عايز تكمّل، أنا هنا 😊
```

### Gulf عامية (after 24h)
```
هلا [الاسم] 👋

ملاحظة بخصوص طلبك — ما تأكدنا العنوان بعد.
إذا ما تبي، عادي! بس إذا تبي تكمل، أنا حاضر 😊
```

## 5. Cancellation Recovery (customer cancelled or didn't confirm)

### Egyptian عامية (after 3 days)
```
أهلاً [الاسم] 👋

لاحظنا إن طلبك اتلغى. لو غيرت رأيك، العرض لسه متاح! 🔥

📦 [اسم المنتج] — [السعر]
🚚 توصيل مجاني + كاش عند الاستلام

عايز تكمّل؟ ابعت "نعم" وأنا أسجّللك الطلب 😊
```

---

*Scripts are starting points. Adjust the dialect to match the client's actual audience — Egyptian عامية doesn't work in KSA, and Gulf عامية doesn't work in Egypt.*
